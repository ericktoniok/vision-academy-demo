# Vision Academy school portal demo

A fictional, standalone responsive portal prototype for a Kenyan school community. Open `index.html` directly in a modern browser. No installation or network connection is required.

## Demo views
- Student: learning snapshot, fictional attendance, CBC learning areas and competencies, assessment history, report card, weekly timetable, assignments and announcements.
- Parent: child summary, sample fee statement and payment history clearly marked as mock, placeholder-only M-Pesa status, transport and meals notes, communication previews.
- Teacher: fictional Grade 4 roster, attendance preview, sample marks and assignments, communication preview.

All names, dates, marks, fees, schedules and records are invented. This is not a real school portal, has no login, backend, data storage, submission, messaging or payment integration, and cannot process payments. Buttons only update local demo text or switch views. The project includes privacy and safeguarding notes and works as a local static page.
